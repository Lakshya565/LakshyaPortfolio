## Overview

Neurify explored a direct connection between an EEG headset and everyday media. I
contributed signal-processing and software work to a system that classified
emotional state in Python and used the result to control Spotify playback.

## System flow

The project moved from EEG input to software classification and then to a visible
application response. That end-to-end loop mattered more than displaying raw
signals: the classification result had to change what the listener experienced.

## Contribution boundary

My verified contribution covered signal processing and software. The available
public material does not separate model design, headset hardware, and integration
ownership in enough detail to assign those areas to me, so I do not claim the
entire system as individual work.

## Takeaway

Neurify is a compact example of why I enjoy hybrid projects. Signal quality,
software interpretation, and product behavior all had to agree before the result
felt meaningful.

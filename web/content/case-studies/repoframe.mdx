## Overview

RepoFrame is a repository-analysis system designed to turn source evidence into grounded project profiles for resumes, portfolios, READMEs, and interview preparation.

<Callout>
  The core product constraint is evidence discipline: generated claims should remain traceable to bounded repository material rather than plausible-sounding inference.
</Callout>

## Problem

Repository content is noisy. Large dependency trees, generated files, incomplete documentation, and framework conventions make it difficult to identify the files that best explain what a project actually does.

## Technical approach

The representative pipeline combines GitHub ingestion, deterministic file ranking, multi-signal stack detection, bounded evidence retrieval, and an allowlisted audit workflow.

## Takeaways

RepoFrame is an example of using deterministic systems and model-driven reasoning as complements: code narrows and validates the evidence space, while the model helps synthesize explanations within those bounds.

## Overview

I designed and built RepoFrame, a full-stack repository-analysis platform that
turns GitHub projects into evidence-backed writeups. One structured project
profile supports four core outputs—resume bullets, README copy, portfolio copy,
and a LinkedIn description—plus a separate interview-preparation workflow.

<Callout>
  The core product constraint is evidence discipline: generated claims should remain traceable to bounded repository material rather than plausible-sounding inference.
</Callout>

## Problem

Repository content is noisy. Dependency trees, generated files, incomplete
documentation, and framework conventions can overwhelm the small set of files
that actually explain a system. Source code also cannot prove a person's role,
intent, team boundary, or measured impact, while user recollection alone can
overstate what the repository supports.

## Technical approach

RepoFrame first collects repository metadata, structure, languages, and selected
text content through the GitHub API. Deterministic filtering, file ranking, and
multi-signal stack detection narrow the evidence before any model request. User
context is kept separate for facts that code cannot establish, such as purpose,
ownership, and outcome.

The backend then fits the rendered request into a bounded prompt budget and
validates structured output before it reaches the interface. Generation happens
only after an explicit user action, with credentials and paid operations kept on
the backend.

## Architecture

The Next.js and TypeScript frontend presents progressive analysis, context
collection, generated outputs, revisions, saved projects, and audit results. A
FastAPI and Python backend owns GitHub access, deterministic analysis, generation,
verification, rate limits, and persistence. Supabase provides authentication and
project storage, while a read-only GitHub App supplies fine-grained repository
access.

Core analysis streams independent stages as they finish. Bounded caches,
stale-while-revalidate behavior, request deduplication, GitHub ETags, deferred
commit statistics, and isolated card errors prevent one slow or failed stage
from collapsing the entire route.

## Evidence Investigator

The optional Agentic Audit does not receive unrestricted repository access. Its
Evidence Investigator can search authorized paths and read additional safe text
files when the initial evidence is insufficient. The verifier then labels claims
by support level and retains the evidence behind each verdict.

This is deliberately different from asking a model to judge its own answer in a
single ungrounded pass: deterministic boundaries decide what can be inspected,
and the tool-using verifier must operate inside that evidence space.

## Takeaways

RepoFrame treats deterministic systems and model-driven reasoning as
complements. Code narrows, budgets, and validates the evidence space; the model
synthesizes within it. That division makes the generated story more useful
because a developer can trace and defend it instead of trusting fluent output at
face value. Overall, this project taught me about the importance of cross-checking
what an LLM generates, as well as enabled me to develop more extensively with AI.
I also got to play around with GitHub and OpenAI API integration, which is something
I've wanted to leave my personal mark in once I learned that they existed!
